# MASSS67 BRAND DNA — CORE DESIGN CONSTITUTION

This document governs all UI, layout, styling, imagery, typography, component design, and interactions for **MASSS67**.

## 1. PROJECT VISION & BRAND PERSONALITY
MASSS67 is a premium competitive multiplayer quiz platform. Joining MASSS67 feels like entering an online multiplayer game lounge.

**Brand Attributes**: Confident, Premium, Competitive, Social, Modern, Energetic, Clean, Friendly, Fast, Original.
**Strict Prohibitions**: Never feel corporate, educational, childish, cartoonish, futuristic, cyberpunk, crypto-inspired, AI-generated, dashboard-like, or template-based.

## 2. BRANDING & WORDMARK RULES
- **Wordmark Integrity**: The `MASSS67` wordmark MUST ALWAYS remain a single solid color.
- **NEVER** split "MASSS" and "67" into different colors.
- **NEVER** apply gradients to the wordmark.
- **NEVER** outline the logo, add glow, or apply 3D effects.

## 3. COLOR & SURFACES PHILOSOPHY
- Calm, sophisticated foundation (deep rich background `#080B16`, surface `#111827`, card `#141A2E`).
- Text uses warm whites and soft grays (avoid harsh pure white).
- Accent colors (`#6C4DFF` / `#00D8FF`) are reserved strictly for primary user interactions, not blanket decoration.
- Personality is driven by high-quality photography and cover art, not interface decorative gimmicks.

## 4. TYPOGRAPHY
- Headings: **Plus Jakarta Sans** (or Geist / Manrope)
- Body: **Inter**
- Numbers & Ratings: **Sora**
- One consistent typography family across all screens.

## 5. IMAGERY & ICONS
- **NEVER** use emojis as category icons or section graphics.
- **NEVER** use clip-art or generic AI gaming graphics.
- Use authentic, curated cover photography for categories (stadiums for sports, labs for science, architecture for history, workstations for dev/tech).

## 6. NON-NEGOTIABLE UI RULES
- Never rely on gradients or glowing borders around every element.
- Never use split-colored brand text.
- Never overuse glassmorphism.
- Never use oversized hero marketing sections.
- Never fill empty space with decorative graphics.
- Design for immediate playability and interaction, not explanation.
